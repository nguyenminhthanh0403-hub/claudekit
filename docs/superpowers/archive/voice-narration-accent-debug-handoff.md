## Reproducing the scratch A/B script (in case the scratch dir is gone)

```python
#!/usr/bin/env python3
"""One-time diagnostic: does raising cfg_weight fix accent drift in the
Chatterbox clone? Generates the SAME short sentence at a few cfg_weight
values, holding everything else at the pipeline's existing defaults, so the
user can A/B by ear. Scratch-only, not part of the project."""
import sys
from pathlib import Path

ROOT = Path("/Users/thanhnguyen/minhthanh0403/claude-projects/claudekit/bullion-live-map")
VOICE_SAMPLE = ROOT / "audio" / "voice_sample" / "user_voice.wav"
OUT_DIR = Path(__file__).resolve().parent

TEXT = ("The central bank that controls interest rates and money supply. "
        "It keeps prices stable, supports jobs, and lends as a last resort in crises.")

import torchaudio as ta
from chatterbox.tts import ChatterboxTTS

model = ChatterboxTTS.from_pretrained(device="cpu")

CONFIGS = [
    ("baseline_cfg05", dict(cfg_weight=0.5, exaggeration=0.5)),   # current pipeline default
    ("cfg08",           dict(cfg_weight=0.8, exaggeration=0.5)),  # hypothesis: stronger prompt adherence
    ("cfg08_exag03",    dict(cfg_weight=0.8, exaggeration=0.3)),  # + less generative drift
]

for name, kwargs in CONFIGS:
    print(f"Generating {name} ({kwargs}) ...")
    wav = model.generate(TEXT, audio_prompt_path=str(VOICE_SAMPLE), **kwargs)
    out_path = OUT_DIR / f"{name}.wav"
    ta.save(str(out_path), wav, model.sr)
    print(f"  wrote {out_path}")

print("DONE")
```

## Verification idioms used in this project (for the resuming session)

- `ChatterboxTTS.generate` signature (confirmed this session via
  `inspect.signature(ChatterboxTTS.generate)` inside `.venv-narration`):
  `(self, text, repetition_penalty=1.2, min_p=0.05, top_p=1.0, audio_prompt_path=None,
  exaggeration=0.5, cfg_weight=0.5, temperature=0.8)`.
- To check a `.wav` file's basic properties without playing it (channels, sample rate,
  duration): Python stdlib `wave` module, `wave.open(path, 'rb')`, `getnchannels()` /
  `getframerate()` / `getnframes()`.
- Audible correctness (accent, voice likeness, mispronunciation) **cannot be verified by
  any automation in this project** — Chrome throttles real audio playback in
  automated/headless tabs, and there is no way to have an agent "listen." Every
  audio-quality judgment in this effort has to come from the user directly, via
  `afplay <path>` in Terminal or opening the file in Finder/QuickTime.
- Long CPU-bound Chatterbox generation runs (whether the real 39-clip pipeline or a
  scratch experiment) are at real risk of being killed mid-run by this harness — this has
  now happened at least twice in this project. Always treat partial output on disk as
  valid/usable rather than assuming a killed run produced nothing.

  main`); no `gh` CLI installed.
